TECHNICAL

The Fullscreen API

A legitimate browser feature weaponized for UI deception

The HTML5 Fullscreen API allows any web page to expand a DOM element to cover the entire screen, hiding the browser’s address bar, tabs, and all security indicators. While designed for video players and games, it can be abused to simulate entire operating system and browser interfaces.

The API requires a user gesture (click) to activate, providing minimal protection. Once in fullscreen, the browser shows only a brief, dismissible notification — easily overlooked by unsuspecting users.

ENTER
element.requestFullscreen()

Requests the element be displayed in fullscreen mode. Requires a user interaction to invoke.

EXIT
document.exitFullscreen()

Programmatically exits fullscreen. ESC key always works — this cannot be overridden by web pages.

EVENT
fullscreenchange

Fires when the browser enters or exits fullscreen, allowing state-based UI manipulation.

Why This Works

  • Browser notification is brief and easily missed
  • All browser chrome (URL bar, tabs) disappears
  • Fake OS UI is visually indistinguishable
  • Victim trusts the familiar YouTube interface
  • No malware required — pure web technology

DEFENSE

Protecting Yourself

Key practices to identify and avoid fullscreen-based UI spoofing attacks

Heed the Notification

Browsers always show a notification when entering fullscreen. If a site triggered it unexpectedly, exit immediately with ESC.

Always Verify the URL

Press ESC and check the real address bar before entering credentials. A fake interface can spoof the display — not the actual URL.

ESC Always Works

No website can override the browser’s ESC key behavior to exit fullscreen. It’s your guaranteed escape — and it cannot be blocked.

Look for Subtle Tells

Spoofed interfaces may have pixel imperfections, wrong system fonts, or inconsistent scaling. Real websites never request fullscreen just to show content.

Be Sceptical of Requests

Video players and games may legitimately use fullscreen. But a general webpage or a link destination should never need to enter fullscreen on click.

Keep Browsers Updated

Modern browsers have improved fullscreen notifications and protections. Always use the latest version and enable automatic security updates.

Modern Browser Mitigations

Since Feross’s original 2012 disclosure, browsers have added mandatory user-gesture requirements, prominent fullscreen banners, ESC key protections, and visual indicators that cannot be hidden by web pages. However, social engineering remains effective — user awareness is still the strongest defense.
